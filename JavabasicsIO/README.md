# Java Syntax and Basic I/O

## Objective
This project demonstrates Java syntax and basic input/output operations using the Scanner class.

## Features
- Takes user name as input
- Takes user age as input
- Displays a personalized greeting

## Technologies Used
- Java
- Eclipse IDE

## Sample Output

Enter your name: Sai Charan
Enter your age: 20

Hello Sai Charan!
You are 20 years old.
Welcome to Java Programming!
